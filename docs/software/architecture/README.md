# Software architecture

- [contracts/](contracts/) state what the current implementation must mean.
- [adr/](adr/) records foundational decisions, rationale, applicability, and consequences.
- [audits/](audits/) records implementation-boundary reviews and migration checks.
- [notes/](notes/) holds non-ADR design notes that remain useful but are not themselves normative.

When documents disagree, use the architecture version, accepted ADR applicability, and current contract to resolve the conflict. Sprint documents must not redefine architecture independently.
