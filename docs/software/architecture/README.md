# Software architecture

- [contracts/](contracts/) state what the current implementation must mean.
- [adr/](adr/) records foundational decisions, rationale, applicability, and consequences.
- [audits/](audits/) records implementation-boundary reviews and migration checks.
- [notes/](notes/) holds non-ADR design notes that remain useful but are not themselves normative. Version 3 migration notes: [PROJECT_NOTE_V2_TO_V3_PIVOT.md](notes/PROJECT_NOTE_V2_TO_V3_PIVOT.md), [V3_CODE_INVENTORY.md](notes/V3_CODE_INVENTORY.md), [V3_MIGRATION_MAP.md](notes/V3_MIGRATION_MAP.md).

When documents disagree, use the architecture version, accepted ADR applicability, and current contract to resolve the conflict. Sprint documents must not redefine architecture independently. Version 3 master contract: [V3_PROJECT_PLAN.md](../V3_PROJECT_PLAN.md).
