# Software planning

- [ACTIVE_SPRINT.md](ACTIVE_SPRINT.md) identifies the current execution document.
- [BACKLOG.md](BACKLOG.md) contains accepted work that is not assigned to a sprint.
- [sprints/v2/](sprints/v2/) contains the active staged Version 2 rearchitecture.
- [sprints/v1/](sprints/v1/) preserves the completed Version 1 execution record.

Sprint documents implement accepted architecture; they do not independently redefine it. Completed work should not remain in the active backlog.
