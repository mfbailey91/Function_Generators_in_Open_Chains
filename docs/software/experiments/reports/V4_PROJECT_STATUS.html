One-sentence verdict

What the project has established so far.

Certified monotonic transmissions change planning through \(\mathcal U \xrightarrow{g} \mathcal Q \xrightarrow{f} \mathcal X\); Versions 1–3 froze that question under graph, lattice, and planner-independent contracts, and Version 4 now owns one verified transmission geometry plus a mounted-Q corrective span bank. V4.2C has implemented the OMPL planner-geometry portfolio that will diagnose how that map enters sampling, optimization, and U/Q/X projections — descriptively, in free space, without a global ranking.

Mechanism embedding remains the scientific object of study.

  • Authoritative planning state is complete PhysicalState encoded in \(U\).
  • Mounted \(Q\) follows ADR-029; native follower angles are not robot joints.
  • Local motion is input-linear; objective is Euclidean actuator travel.
  • Start is exact; goals are a frozen finite physical set from V4.2B.
