One-sentence verdict

What the project has established so far.

Certified monotonic transmissions change planning through the map \(\mathcal U \xrightarrow{g_m} \mathcal Q \xrightarrow{f} \mathcal X\); Version 2 measured that effect under a fixed lattice formulation, and Version 3 now asks the same scientific question across interchangeable planners without letting any backend redefine physical state, goals, validity, or objective semantics.

Locked V3 design rules

  • Exact start remains exact; goal is a predicate / region.
  • Local motion is continuous; lattice adjacency only proposes candidates.
  • Actuator-travel objective is authoritative for reported path cost.
  • OMPL is an algorithm backend (ADR-025), never the source of physical identity.
  • Task class from direct-connector attempt is independent of planner outcome (ADR-026).
  • No silent reinterpretation of frozen V1/V2 evidence.
  • Core package must not hard-depend on OMPL (optional gate).
