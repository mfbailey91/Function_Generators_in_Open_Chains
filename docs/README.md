# Inequality Mechanisms paper package

Open `inequality_mechanisms_paper_draft.md` in a Markdown editor from this folder.
The `figures/` directory must remain beside it for images to render.

Recommended editors:
- Obsidian
- Typora
- VS Code with Markdown math support
- GitHub

A separate self-contained Markdown file and self-contained HTML file are also
provided outside this ZIP for environments that cannot resolve relative images.
